🧬 Bio-Pipeline: DNA Sample Validation

A beginner-level Python project simulating a biological sample-processing pipeline.

Features:

- Represents DNA samples using Python classes and objects.
- Stores sample names and sequence lengths.
- Checks for zero-length samples.
- Demonstrates loops, conditional statements, and exception handling.

Technologies: Python, Object-Oriented Programming (OOP).

Future Scope: FASTA file processing, DNA sequence analysis, and nucleotide composition calculations.
